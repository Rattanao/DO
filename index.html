ทุกใบ เริ่มเก็บค่า DEM. วันที่ · DG (UN / CLASS) เพิ่ม SPECIAL CONTAINER · ตู้เย็น (20RF / 40RH / TEMP) เพิ่มวันเริ่มเก็บค่าไฟ · ISO TANK + DG เติมแค่ SPECIAL CONTAINER · CFS SPLIT (B/L หลัก + A, B, C…) ไม่เติม DEM · CFS เดี่ยว เติมเหมือน CY · หน้า ATTACHED RIDER ไม่เติม
รวมไฟล์: ทีละ B/L เรียง DO → ATTACHED → ใบเปิดตู้ / คำร้อง · ตรวจใบเปิดตู้: ชื่อเรือ, CNTR, CNEE, B/L NO., STATUS (FCL = CY, CFS = เปิดตู้, LCL = ขนส่ง)
ปริ้น x2: CY ซ้อนกันทีละ B/L (1,1,2,2) · CFS แยกเป็น 2 ชุดต่อ B/L หลัก (A,B,C,A,B,C)
วันที่: ใส่ CHECK DEM หรือเติมเองที่ช่อง DEM. / ค่าไฟ (เติมอย่างใดอย่างหนึ่งหรือทั้งสองอย่าง) แล้วกด ประมวลผล (ใช้กับทุก B/L ที่ CHECK DEM ไม่มีวันที่) · แก้ทีละ B/L ได้ที่ช่องวันที่ในตาราง แล้วกด ประมวลผล · ค่าไฟที่ไม่มีวันที่เลยใช้ ATA + 3 วัน
ไฟล์ถูกประมวลผลในเบราว์เซอร์ของคุณเท่านั้น ไม่มีการอัปโหลดไปที่ใด

ตรวจใบเปิดตู้ / คำร้อง เทียบกับ DO
