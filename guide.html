DO

เติมวันเริ่มเก็บค่า DEM วันเริ่มเก็บค่าไฟ และ SPECIAL CONTAINER ลงท้ายใบ Cargo Delivery Order ทุกหน้าในครั้งเดียว ดึงวันที่จาก CHECK DEM หรือพิมพ์เอง แล้วได้ไฟล์พร้อมปริ้น 2 ชุด

DO.pdf+ CHECK DEM.xlsx→ DO-DEM.pdf+ DO-DEM-PRINT x 2.pdf
ทำออนไลน์ (ไม่ต้องติดตั้ง) ดาวน์โหลดโปรแกรม (ZIP) เปิดหน้า GitHub

ใช้งานออนไลน์

ไม่ต้องติดตั้งอะไร ไฟล์ประมวลผลในเบราว์เซอร์ของเครื่องที่ใช้อยู่ ไม่มีการอัปโหลดไปที่ใด

  1. ลากไฟล์ DO (.pdf) มาวาง ใส่ได้ 1 ไฟล์หรือมากกว่า เว็บจะรวมต่อกันตามลำดับ

    ไฟล์ CHECK DEM.xlsx ใส่หรือไม่ใส่ก็ได้ ถ้าไม่ใส่ ให้เติมช่อง DEM. วันที่ และ/หรือ ค่าไฟ วันที่ เอง

  2. กด ประมวลผล

    ตารางบอกทีละหน้าว่าเติมอะไร ช่องวันที่สีแดง = ยังไม่มีวันที่ แก้ทีละ B/L ในตารางได้ แล้วกดประมวลผลอีกครั้ง

  3. กด ดาวน์โหลด DO-DEM.pdf (x1 + x2) หรือ ปริ้น x2

    ได้ 2 ไฟล์ DO-DEM.pdf (ชุดเดียว) และ DO-DEM-PRINT x 2.pdf (เรียงตามลำดับปริ้น) ครั้งแรกเบราว์เซอร์อาจถามว่า “อนุญาตให้ดาวน์โหลดหลายไฟล์” ให้กดอนุญาต

ติดตั้งครั้งแรก

ทำครั้งเดียวต่อเครื่อง ใช้ Windows (ถ้าใช้แบบออนไลน์ ข้ามส่วนนี้ได้เลย)

  1. ติดตั้ง Python 3 จาก python.org/downloads

    หน้าแรกของตัวติดตั้ง ติ๊ก ☑ Add python.exe to PATH ก่อนกด Install Now

  2. ดาวน์โหลดโปรแกรม กดปุ่ม “ดาวน์โหลดโปรแกรม (ZIP)” ด้านบน

    คลิกขวาที่ไฟล์ ZIP → Extract All แล้วเก็บโฟลเดอร์ไว้ที่ไหนก็ได้ เช่น Documents

  3. รันครั้งแรกต้องต่ออินเทอร์เน็ต

    โปรแกรมจะติดตั้งไลบรารีที่ต้องใช้ (pymupdf, openpyxl) ให้เองอัตโนมัติ ใช้ฟอนต์ Angsana New ที่มากับ Windows

ใช้งานทุกครั้ง (โปรแกรมในเครื่อง)

  1. วางไฟล์ในโฟลเดอร์ input

    ไฟล์ D/O ที่ชื่อขึ้นต้นด้วย DO เช่น DO-SWSR.pdf และไฟล์ CHECK DEM.xlsx (จาก Check-dem)

  2. ดับเบิลคลิก run-do.bat

    หน้าจอดำจะแสดงทีละหน้าว่าเติมอะไร หน้าที่ไม่มีวันที่จะขึ้นว่า ** ไม่มีวันที่ DEM ใน CHECK DEM **

  3. เปิดผลที่ output\DO-DEM.pdf และ output\DO-DEM-PRINT x 2.pdf

    ไฟล์ใน input ไม่ถูกแก้ ถ้าเปิดไฟล์ผลค้างไว้ ต้องปิดก่อนรันใหม่

ตัวอย่างประกอบเท่านั้น วันที่สมมติ

วันที่มาจากไหน

  • DEM = ช่อง DEM. ใน CHECK DEM ของ B/L นั้น
  • ค่าไฟ = ช่อง REC. ถ้าว่างใช้ ATA + 3 วัน
  • House B/L เช่น ...038A ที่ไม่มีใน CHECK DEM ใช้วันที่ของ B/L หลัก ...038
  • บนเว็บ: วันที่ที่แก้ในตาราง > CHECK DEM > ช่องวันที่ด้านบน

ปริ้น x2

  • หนึ่ง B/L = หน้า D/O + หน้า ATTACHED RIDER ของมัน
  • CY: ซ้อนกันทีละ B/L เช่น 1, 1, 2, 2
  • CFS: แยกเป็น 2 ชุดต่อ B/L หลัก เช่น 038, 038A, 038B, 038, 038A, 038B
  • ใส่ไฟล์ที่เติมแล้วซ้ำ หน้าที่เติมแล้วจะถูกข้าม ไม่เติมซ้อน
