DO

คำนวณวันเริ่มเก็บค่า DEM จาก Freedays แล้วเติมวันเริ่มเก็บค่า DEM วันเริ่มเก็บค่าไฟ และ SPECIAL CONTAINER ลงท้ายใบ Cargo Delivery Order ทุกหน้าในครั้งเดียว รวมกับ ATTACHED และใบเปิดตู้ ตรวจใบเปิดตู้เทียบกับ DO แล้วได้ไฟล์พร้อมปริ้น 2 ชุด Work out the DEM start dates from Freedays, then write the DEM / reefer-power / SPECIAL CONTAINER notes on every Cargo Delivery Order page in one go, merge them with the ATTACHED sheets and container-opening forms, check those forms against the D/O, and get a file ready to print twice.

ใช้งานออนไลน์Use it online

ไม่ต้องติดตั้งอะไร ไฟล์ประมวลผลในเบราว์เซอร์ของเครื่องที่ใช้อยู่ ไม่มีการอัปโหลดไปที่ใด หน้าเว็บเป็นภาษาอังกฤษNothing to install. Files are processed in your browser only; nothing is uploaded.

  1. ① CHECK DEM (เมนูด้านบนของเว็บ): ลากไฟล์ Freedays (.xls / .xlsx) ใส่วันที่ ATA แล้วกด Calculate ① CHECK DEM (menu at the top): drop the Freedays file (.xls / .xlsx), enter the ATA and press Calculate

    คำนวณเสร็จ ผลถูกส่งไปหน้า ② DO ให้เองทันที ไม่ต้องดาวน์โหลดแล้วใส่ใหม่ — กด Go to DO → เพื่อไปหน้า DO (ถ้าเปิดหน้า DO ไว้อีกแท็บ จะรับและประมวลผลใหม่ให้เอง) หรือกด Download CHECK DEM.xlsx เก็บไว้ก็ได้ The result goes to ② DO by itself — no download / upload. Press Go to DO → to open it (a DO tab already open takes it and processes again). Download CHECK DEM.xlsx if you want to keep the file.

  2. ② DO: ลากไฟล์ DO / ATTACHED / ใบเปิดตู้ (.pdf) มาวาง ใส่ได้หลายไฟล์ ลำดับไหนก็ได้ เว็บรวมทีละ B/L เรียง DO → ATTACHED → ใบเปิดตู้ → คำร้อง ② DO: drop the DO / ATTACHED / container-opening form files (.pdf) — several files in any order; each B/L is merged as DO → ATTACHED → opening form → removal request

    ไม่มี CHECK DEM ก็ได้ ให้เติมช่อง DEM. date และ/หรือ Reefer power date เอง No CHECK DEM? Type the DEM. date and/or Reefer power date instead.

  3. กด ProcessPress Process

    ตารางบอกทีละหน้าว่าเติมอะไร ช่องวันที่สีแดง = ยังไม่มีวันที่ แก้ทีละ B/L ในตารางได้ แล้วกด Process อีกครั้ง The table shows what was written on each page. A red date cell = no date yet; change one B/L in the table and press Process again.

  4. กด Download DO-DEM.pdf (x1 + x2) หรือ Print x2Press Download DO-DEM.pdf (x1 + x2) or Print x2

    ได้ 2 ไฟล์ DO-DEM.pdf (ชุดเดียว) และ DO-DEM-PRINT x 2.pdf (เรียงตามลำดับปริ้น) ครั้งแรกเบราว์เซอร์อาจถามว่า “อนุญาตให้ดาวน์โหลดหลายไฟล์” ให้กดอนุญาต You get DO-DEM.pdf (one set) and DO-DEM-PRINT x 2.pdf (print order). The first time the browser may ask to allow multiple downloads — allow it.

ตรวจใบเปิดตู้ / คำร้องContainer-opening form / removal request check

ใส่ใบเปิดตู้มาพร้อม DO เว็บเทียบให้ทันที แสดงเฉพาะ B/L ที่ต้องแก้ ช่องที่ไม่ตรงขึ้นสีแดง และมีคำเตือนด้านบนของหน้า Drop the forms together with the DO and they are checked at once. Only B/Ls that need a correction are listed; wrong fields are red and a warning shows at the top.

  • เทียบ ชื่อเรือ (ไม่นับ “V.”), วันที่เรือเข้า, CNTR (รวมตู้ในหน้า ATTACHED RIDER), CNEE (ชื่อยาวที่ขึ้นบรรทัด 2 ได้), B/L NO., STATUS Compared: vessel (“V.” ignored), arrival date, CNTR (incl. ATTACHED RIDER pages), CNEE (names wrapping onto a 2nd line are fine), B/L NO., STATUS
  • วันที่เรือเข้าที่ไม่ตรง แก้ตาม DO ให้อัตโนมัติ (DO 2026.11.04 → ใบเปิด 4-Nov-26) A wrong arrival date is corrected to the D/O's automatically (DO 2026.11.04 → form 4-Nov-26)
  • STATUS: FCL = CY/CY หรือ CFS/CY · CFS = เปิดตู้ · LCL = ขนส่ง (เขียนต่อด้วยภาษาไทยได้ เช่น LCL (ขนส่งแรงงาน-เรือ)) STATUS: FCL = CY/CY or CFS/CY · CFS = devanning · LCL = transport (Thai after it is fine, e.g. LCL (ขนส่งแรงงาน-เรือ))
  • แก้ค่าในช่องสีแดง แล้วกด Correct the form with these values → ตรวจซ้ำเป็นสีเขียว Edit the red cells and press Correct the form with these values → it is checked again and turns green
  • Save over the original file (Chrome / Edge) หรือ Download corrected form Save over the original file (Chrome / Edge) or Download corrected form

วันที่มาจากไหนWhere the dates come from

  • DEM = ช่อง DEM. ใน CHECK DEM ของ B/L นั้นDEM = the B/L's DEM. cell in CHECK DEM
  • ค่าไฟ = ช่อง REC. ถ้าว่างใช้ ATA + 3 วันReefer power = REC.; blank → ATA + 3 days
  • House B/L เช่น ...038A ที่ไม่มีใน CHECK DEM ใช้วันที่ของ B/L หลัก ...038A house B/L such as ...038A not in CHECK DEM uses its master ...038
  • บนเว็บ: วันที่ที่แก้ในตาราง > CHECK DEM > ช่องวันที่ด้านบนOn the web: date typed in the table > CHECK DEM > dates typed above

ปริ้น x2Print x2

  • หนึ่ง B/L = หน้า D/O + ATTACHED RIDER / ATTACHED / ใบเปิดตู้ ของมันOne B/L = its D/O page + its ATTACHED RIDER / ATTACHED / form pages
  • CY: ซ้อนกันทีละ B/L เช่น 1, 1, 2, 2CY: two of each B/L in a row, e.g. 1, 1, 2, 2
  • CFS: แยกเป็น 2 ชุดต่อ B/L หลัก เช่น 038, 038A, 038B, 038, 038A, 038BCFS: two sets per master B/L, e.g. 038, 038A, 038B, 038, 038A, 038B
  • ใส่ไฟล์ที่เติมแล้วซ้ำ หน้าที่เติมแล้วจะถูกข้าม ไม่เติมซ้อนA file that was already filled can be dropped again — filled pages are skipped

ติดตั้งครั้งแรก (โปรแกรมในเครื่อง)First-time install (desktop program)

ทำครั้งเดียวต่อเครื่อง ใช้ Windows (ถ้าใช้แบบออนไลน์ ข้ามส่วนนี้ได้เลย)Once per computer, Windows. Skip this if you use the web pages.

  1. ติดตั้ง Python 3 จากInstall Python 3 from python.org/downloads

    หน้าแรกของตัวติดตั้ง ติ๊ก ☑ Add python.exe to PATH ก่อนกด Install NowOn the first installer screen tick ☑ Add python.exe to PATH before Install Now

  2. ดาวน์โหลดโปรแกรม กดปุ่ม “Download program (ZIP)” ด้านบนDownload the program with “Download program (ZIP)” above

    คลิกขวาที่ไฟล์ ZIP → Extract All แล้วเก็บโฟลเดอร์ไว้ที่ไหนก็ได้ เช่น DocumentsRight-click the ZIP → Extract All, keep the folder anywhere, e.g. Documents

  3. รันครั้งแรกต้องต่ออินเทอร์เน็ตThe first run needs the internet

    โปรแกรมติดตั้งไลบรารีที่ต้องใช้ (pymupdf, openpyxl) ให้เอง ใช้ฟอนต์ Angsana New ที่มากับ WindowsIt installs its libraries (pymupdf, openpyxl) by itself and uses Windows' Angsana New font

ใช้งานทุกครั้ง (โปรแกรมในเครื่อง)Every time (desktop program)

  1. วางไฟล์ในโฟลเดอร์ inputPut the files in the input folder

    ไฟล์ D/O (และ ATTACHED / ใบเปิดตู้ ถ้ามี) และไฟล์ CHECK DEM.xlsxThe D/O PDF(s) (plus ATTACHED / opening forms if any) and CHECK DEM.xlsx

  2. ดับเบิลคลิก run-do.batDouble-click run-do.bat

    หน้าจอดำแสดงทีละหน้าว่าเติมอะไร และตารางใบเปิดตู้ที่ต้องแก้The black window lists what was written on each page and the forms that need a correction

  3. เปิดผลที่Open output\DO-DEM.pdf และand output\DO-DEM-PRINT x 2.pdf

    ไฟล์ใน input ไม่ถูกแก้ ถ้าเปิดไฟล์ผลค้างไว้ ต้องปิดก่อนรันใหม่Files in input are not changed. Close an open result file before running again.
